# Yrdly

Yrdly is building the digital backbone for Nigerian neighborhoods — connecting residents, local vendors, and community services in one place.

🌐 **Website:** [yrdly.ng](https://yrdly.ng)
📱 **Mobile app:** Built with React Native & Expo (iOS/Android)

---

### What we're building

- **Yrdly Web** — the neighborhood hub where residents discover and connect with what's around them
- **Yrdly Mobile** — a native app bringing the same experience on the go

### Tech we use

`React` · `Next.js` · `TypeScript` · `React Native` · `Expo` · `Supabase` · `Tailwind CSS` · `Vercel`
